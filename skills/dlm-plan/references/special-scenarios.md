# DLM Plan 7 Special Scenarios

## Fuzzy Request

If the desired behavior or evidence is unclear, create a small discovery/Spike task with explicit questions and exit criteria. Do not invent an implementation plan from weak evidence.

## Existing Epic Overlap

Decide between a new Epic and an appended Subtask using ownership, lifecycle, release boundary and validation cohesion. Do not use a fixed overlap percentage.

## Append to Existing Epic

Read the Epic and contract, choose the next ID, verify dependency topology, create a schema-2 manifest, then synchronize the README index. Deep design is required when the change affects a contract, safety path, persisted format or multiple owners—not because an arbitrary number of files is touched.

## Spike

A Spike may defer Domain-specific documents while exploring, but it still loads repository rules, project BRIEF and global L0. It is read-only unless the user authorizes an experiment. The report must separate observations, hypotheses and recommended follow-up.

## External Material

External reading does not authorize copying. Keep a source reference by default. Import only with explicit authorization and after selecting a project-local destination and checking sensitivity/licensing.
