## 操作指南

### 新建 Epic
1. 从 `dlm-plan/templates/epic_template.md` 复制模板
2. 创建 `Tasks/E{NNN}_{短名}/` 目录及子目录 (plan/, audit/, subtasks/, references/)
3. 填写 README.md
4. 在上方对应象限添加索引行

### LLM Session 规则

| 时机 | 必须做的事 |
|------|-----------| 
| **Session 开始** | 一次性锁定项目/任务后，加载当前决定所需的最小 `L0`、backlog、Epic/Subtask 和源码上下文；身份稳定时不重复完整初始化 |
| **执行任务时** | 根据子任务的 `<context_manifest>` 加载文件 |
| **结果稳定后** | 仅当用户目标、适用合同或真实加载/决策消费者需要时执行一次 `dlm-sediment`; 复用现有证据同步 Task/L2/L1, 不因纯行政变化重跑无关验证 |
